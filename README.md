# Actuent LAWP for WordPress

Make your WordPress site readable and actionable by AI agents like ChatGPT and Claude.

- Publishes your site as [LAWP](https://github.com/localilabs/lawp) at `/.well-known/lawp.json`, built from your site name, tagline and published pages.
- **Search action:** agents can search your posts and pages.
- **Contact action:** agents can send you a message on their user's behalf, emailed to your admin address. Only requests signed by [Actuent](https://actuent.ai) are accepted.
- Custom actions (e.g. bookings) via JSON in Settings → Actuent.

Sites with native LAWP rank higher on Actuent, and their actions become executable by AI agents.

## Install

Download `actuent-lawp.zip` from [Releases](https://github.com/localilabs/actuent-wordpress/releases), then in WordPress go to **Plugins → Add New → Upload Plugin**. Or copy the `actuent-lawp` folder into `wp-content/plugins/`.

Check your setup with the [LAWP Checker](https://docs.actuent.ai/#checker).
